# NEO VPN Sales Bot

ربات فارسی فروش VPN برای Telegram با اتصال به PasarGuard، فروشگاه، سفارش، کیف پول، پنل مدیریت وب و تأیید کارت‌به‌کارت از پیامک بلو.

## نصب آزمایشی

روی Ubuntu 22.04/24.04 amd64 این دستور را در ترمینال سرور اجرا کن:

```bash
curl -fsSL https://raw.githubusercontent.com/yasinmalek82/neo-vpn-sales-bot-public/main/setup.sh | sudo sh
```

این لینک ثابت، دانلودکنندهٔ نسخهٔ تأییدشده را باز می‌کند؛ بسته از GitHub دانلود، SHA256 بررسی و نصب‌کنندهٔ تعاملی اجرا می‌شود. حساب یا توکن GitHub لازم نیست. نصب‌کننده تنظیمات خصوصی و تأیید شروع سرویس‌ها را از تو می‌پرسد. برای دانلود دستی از [آخرین بستهٔ نصب](https://github.com/yasinmalek82/neo-vpn-sales-bot-public/releases/latest) استفاده کن.

- [راهنمای نصب](docs/TEST_INSTALL_FA.md)
- [تأیید پیامک بلو و تنظیم Shortcut آیفون](docs/BANK_SMS_BLU.md)
- [مستندات فنی](docs/README.md)

این مخزن snapshot عمومیِ کد است؛ تاریخچه و گزارش‌های عملیاتی خصوصی در آن نیستند. هیچ توکن عملیاتی، اطلاعات مشتری یا پایگاه داده همراه بسته نیست. تنظیمات خصوصی هنگام نصب روی سرور ساخته می‌شوند.

در منو، گزینهٔ `5 — Update` نسخهٔ تازه را با حفظ تنظیمات و داده‌ها اعمال می‌کند؛ گزینهٔ `6 — Uninstall` حذف با حفظ داده یا حذف دادهٔ فعال همراه بکاپ خصوصی دارد. [راهنمای Update و Uninstall](docs/INSTALLER_LIFECYCLE_FA.md).

این انتشار برای آزمایش مستقل نصب و پرداخت است. تست واقعی آیفون، واریز بانک و تحویل سرویس باید روی نصب خودت انجام شود. انتقال مشتریان در این نصب‌کننده انجام نمی‌شود.
