# NEO VPN Sales Bot

**فروشگاه فارسی اشتراک VPN در تلگرام، متصل به PasarGuard**

با NEO می‌توانی پلن بفروشی، سفارش و کیف پول را مدیریت کنی و اشتراک را در تلگرام تحویل بدهی. PasarGuard سرویس VPN را اداره می‌کند و NEO فروشگاه، پرداخت و تحویل را مدیریت می‌کند.

| فروشگاه | پرداخت | عملیات |
| --- | --- | --- |
| خرید، تمدید، تخفیف و قیمت نماینده | کارت‌به‌کارت، رسید دستی و تأیید پیامک بلو | Mini App مدیریت، گزارش‌ها و بکاپ محلی |

## نصب NEO v1

روی **Ubuntu 22.04 یا 24.04 با معماری amd64**، با یک زیردامنهٔ متصل به سرور:

```bash
curl -fsSLO https://raw.githubusercontent.com/yasinmalek82/neo-vpn-sales-bot-public/main/setup.sh
sudo sh setup.sh
```

نصاب نسخهٔ منتشرشده را دریافت و SHA256 را بررسی می‌کند. بسته شامل ایمیج‌های NEO، PostgreSQL و Caddy است. حساب GitHub لازم نیست. نصب‌کننده پیش از راه‌اندازی سرویس‌ها تأیید می‌گیرد.

- [دانلود نسخهٔ ۱](https://github.com/yasinmalek82/neo-vpn-sales-bot-public/releases/tag/v1.0.0)
- [راهنمای نصب، بکاپ و بررسی پیش از فروش](docs/INSTALL_FA.md)
- [تنظیم تأیید خودکار بلو و Shortcut آیفون](docs/BANK_SMS_BLU.md)
- [مدیریت، به‌روزرسانی و حذف نصب](docs/INSTALLER_LIFECYCLE_FA.md)

`sudo neo-bot` منوی مدیریت نصب را باز می‌کند. برای مشاهدهٔ وضعیت مستقیم از `sudo neo-bot status` استفاده کن.

این نسخه برای نصب و راه‌اندازی فروشگاه است. مسیر رسمی انتقال مشتریان میرزا برای نسخهٔ بعد برنامه‌ریزی شده است.
