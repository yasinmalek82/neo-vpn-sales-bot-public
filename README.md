# NEO VPN Sales Bot

ربات فارسی فروش VPN برای Telegram با اتصال به PasarGuard، فروشگاه، سفارش، کیف پول، پنل مدیریت وب و تأیید کارت‌به‌کارت از پیامک بلو.

## نصب آزمایشی

بستهٔ آمادهٔ Ubuntu 22.04/24.04 amd64 را از [Releases](https://github.com/yasinmalek82/neo-vpn-sales-bot-public/releases) بگیر. دستور تک‌خطیِ مخصوص همان نسخه در توضیحات انتشار و فایل `INSTALL.fa.md` قرار دارد. حساب یا توکن GitHub لازم نیست.

- [راهنمای نصب](docs/TEST_INSTALL_FA.md)
- [تأیید پیامک بلو و تنظیم Shortcut آیفون](docs/BANK_SMS_BLU.md)
- [مستندات فنی](docs/README.md)

این مخزن snapshot عمومیِ کد است؛ تاریخچه و گزارش‌های عملیاتی خصوصی در آن نیستند. هیچ توکن عملیاتی، اطلاعات مشتری یا پایگاه داده همراه بسته نیست. تنظیمات خصوصی هنگام نصب روی سرور ساخته می‌شوند.

این انتشار برای آزمایش مستقل نصب و پرداخت است. تست واقعی آیفون، واریز بانک و تحویل سرویس باید روی نصب خودت انجام شود. انتقال مشتریان یا ارتقای نصب قبلی در این نصب‌کننده انجام نمی‌شود.
