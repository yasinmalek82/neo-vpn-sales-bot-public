# بازبینی فنی نصب‌کننده

دامنه: راه‌انداز تک‌خطی، دریافت/استخراج بسته، منوی ترمینال، probe تلگرام/پنل، ذخیرهٔ تنظیمات، شروع/توقف و بازیابی خطا. منوی ترمینال کاملاً انگلیسی است.

| مورد | مشکل | اصلاح و شاهد |
| --- | --- | --- |
| webhook | توقف کامل بدون مسیر انتخاب | تأیید نام ربات؛ امکان ادامه یا تغییر توکن؛ حذف فقط با تأیید صریح در لحظهٔ شروع و بررسی مجدد هویت/وضعیت |
| صف پیام‌ها | شروع polling پیام‌های منتظر را حذف می‌کرد | نصب آزمایشی `POLLING_DROP_PENDING_UPDATES=false` دارد؛ تنظیم در startup مصرف می‌شود؛ رفتار پیش‌فرض نصب‌های دیگر تغییر نکرده |
| نصب ناقص | خطای کپی یا نوشتن، پوشه‌ای می‌گذاشت که تلاش بعدی را مسدود می‌کرد | ساخت در staging خصوصی، اعتبارسنجی Compose، سپس انتشار اتمی؛ شکست فقط staging همین اجرا را پاک می‌کند |
| پاسخ نامعتبر | اشتباه در سؤال فعال‌سازی بلو به «بله» تبدیل می‌شد | تأیید صریح با تکرار سؤال؛ نمایش پیش‌فرض؛ ذخیره و شروع هر دو پیش‌فرض خیر |
| retry | خطای موقت کل فرایند را قطع می‌کرد | retry با همان ورودی یا ورود دوبارهٔ همان اعتبارنامه؛ رازها و پاسخ خام سرویس چاپ نمی‌شوند |
| دانلود دوباره | هر تلاش همهٔ imageها را دوباره دانلود می‌کرد | cache خصوصی با بررسی SHA256 مجدد؛ دانلود ناقص فقط در فایل موقت و جایگزینی پس از تأیید |
| DNS | یک IP صحیح در کنار IPهای اشتباه پذیرفته می‌شد | همهٔ Aها باید همان IP باشند؛ AAAA در این نصب IPv4 رد می‌شود |
| خروج | EOF یا Ctrl+C می‌توانست traceback بدهد | خروج مشخص با کد 130؛ تنظیمات قبلی بازنویسی نمی‌شوند |
| زمان انتظار | بررسی ارتباط می‌توانست بی‌پایان بماند | محدودیت زمانی برای probe و subprocess؛ خطای قابل تکرار بدون چاپ اطلاعات حساس |
| فهم جریان | مراحل و نتیجهٔ ذخیره/شروع روشن نبود | منوی پنج‌گزینه‌ای، مراحل شماره‌دار، خلاصهٔ بدون راز و فرمان ادامهٔ محلی |

رگرسیون‌ها در `tests/unit/test_installer_review.py`، `test_test_installer.py`، `test_github_install.py` و `test_setup_bootstrap.py` قرار دارند. بررسی startup صف از منطق واقعی `bot.main.on_startup` استفاده می‌کند؛ هیچ درخواست واقعی تلگرام/پنل در این تست‌ها انجام نمی‌شود.

محدودیت‌های باز: نصب روی AWS مالک و تراکنش واقعی/آیفون باید بررسی شود؛ سلامت container اثبات SSL عمومی، polling اختصاصی یا تحویل VPN نیست. Update مدیریت‌شده با بکاپ جداگانه اضافه شده است؛ Install همچنان نصب موجود را بازنویسی نمی‌کند. انتقال مشتریان و دیتابیس‌های خارجی/ساختار سفارشی نیازمند مسیر جداست. API تلگرام بدون مصرف پیام‌ها، انحصاری‌بودن polling روی سرور دیگری را ثابت نمی‌کند.

معنای حذف webhook و گزینهٔ حذف پیام‌های منتظر با [مستند رسمی Telegram](https://core.telegram.org/bots/api#deletewebhook) تطبیق داده شد. تغییر webhook واقعی در این بازبینی توسط عامل انجام نشده است؛ عملیات فقط با انتخاب مالک در نصب‌کننده اجرا می‌شود.
