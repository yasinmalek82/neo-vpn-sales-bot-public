# راهنمای نصب و بهره‌برداری NEO

## ۱. آماده‌سازی سرور

- Ubuntu 22.04 یا 24.04 با معماری amd64، دسترسی `sudo` و Python 3.
- یک زیردامنه با رکورد A مستقیم به IPv4 سرور. پورت‌های عمومی 80 و 443 و پورت محلی 8080 باید آزاد باشند. PostgreSQL پورت عمومی ندارد.
- توکن ربات، شناسهٔ عددی مدیر و مالک فروشگاه، آدرس HTTPS پنل PasarGuard و API key آن را آماده کن. برای پرداخت خودکار، اطلاعات کارت مقصد بلو و یک آیفون دریافت‌کنندهٔ پیامک لازم است.
- نصب به دسترسی GitHub، تلگرام، PasarGuard و سرویس صدور گواهی HTTPS نیاز دارد. اگر Docker از قبل موجود نباشد، نصب بسته‌های Docker هم اینترنت می‌خواهد. حدود ۵ گیگابایت فضای آزاد برای نصب در نظر بگیر و برای داده و بکاپ جداگانه ظرفیت بگذار.

## ۲. دریافت و نصب

**نصب آنلاین**

```bash
curl -fsSLO https://raw.githubusercontent.com/yasinmalek82/neo-vpn-sales-bot-public/main/setup.sh
sudo sh setup.sh
```

گزینهٔ `1 — Install a new instance` را بزن. نصاب فایل نسخه را با SHA256 می‌سنجد، ایمیج‌ها را بارگذاری می‌کند و اطلاعات را در سرور می‌گیرد. برای شروع سرویس‌ها در پایان تأیید جداگانه می‌پرسد. مسیر نصب مدیریت‌شده `/opt/neo-test` و نام پروژهٔ Compose آن `neo-test` است. این نام برای سازگاری با نصب‌های موجود حفظ شده است. اگر swap نداری، ساخت ۱ گیگابایت swap فقط با انتخاب صریح انجام می‌شود.

**نصب از فایل**

از [صفحهٔ نسخه](https://github.com/yasinmalek82/neo-vpn-sales-bot-public/releases/tag/v1.0.0)، هر دو فایل آرشیو و checksum را بگیر. سپس در پوشهٔ دانلود اجرا کن:

```bash
sha256sum -c neo-install-linux-amd64-v1.0.0.tar.gz.sha256
tar -xzf neo-install-linux-amd64-v1.0.0.tar.gz
cd neo-install-linux-amd64-v1.0.0
sudo sh install.sh
```

آرشیو ایمیج‌های NEO، PostgreSQL و Caddy را دارد. برای بارگذاری آن‌ها به Docker Hub نیاز نیست. اعتبارسنجی کلیدها، HTTPS و کارکرد ربات همچنان به شبکه نیاز دارند.

## ۳. پرداخت و تحویل

از حساب مدیر `/admin` و از یک حساب دیگر `/start` را بزن. پلن را به گروه صحیح PasarGuard وصل کن. یک خرید کنترل‌شده انجام بده و مبلغ، ثبت پرداخت، تحویل یک کارت سرویس و اتصال VPN را بررسی کن.

اگر بلو را فعال کرده‌ای، [Shortcut نسخه](https://github.com/yasinmalek82/neo-vpn-sales-bot-public/releases/tag/v1.0.0) را به آیفون اضافه کن. نصاب تنظیمات اتصال را در فایل خصوصی `/opt/neo-test/shortcut-settings.json` می‌سازد. راز را فقط در Shortcut وارد کن. اجرای اتومیشن هنگام قفل بودن آیفون و رد تکرار همان پیامک را هم بررسی کن. [راهنمای بلو](https://github.com/yasinmalek82/neo-vpn-sales-bot-public/blob/v1.0.0/docs/BANK_SMS_BLU.md).

بعد از ثبت پرداخت معتبر، صف فعال‌سازی و صف تحویل هر ۵ ثانیه بررسی می‌شوند. مدت پاسخ پنل و تلگرام به زمان تحویل اضافه می‌شود. سفارش نامنطبق یا دیررس را از مسیر بررسی دستی پیگیری کن.

## ۴. عملیات و بکاپ

```bash
sudo neo-bot
sudo neo-bot status
sudo neo-bot logs
```

در نصب تازهٔ نسخهٔ ۱، بکاپ زمان‌بندی‌شدهٔ NEO فعال است و فایل‌ها در volume خصوصی `app_backups` ذخیره می‌شوند. وجود و تازگی بکاپ را چک کن، یک نسخهٔ رمزگذاری‌شده خارج از سرور نگه دار و بازیابی را روی دیتابیس جدا تمرین کن. در ارتقای نصب موجود، تنظیم قبلی بکاپ حفظ می‌شود. [راهنمای به‌روزرسانی و بکاپ خصوصی](https://github.com/yasinmalek82/neo-vpn-sales-bot-public/blob/v1.0.0/docs/INSTALLER_LIFECYCLE_FA.md).

قبل از فروش واقعی، مسیر گزارش‌ها، بررسی دستی رسید، هشدار توقف ربات و بازیابی بکاپ را روی نصب خودت بررسی کن. [چک‌لیست بهره‌برداری](https://github.com/yasinmalek82/neo-vpn-sales-bot-public/blob/v1.0.0/docs/PRODUCTION_CHECKLIST.md).

تنظیمات نصب، ایمیج‌ها و داده‌های فعال هنگام به‌روزرسانی با مکانیزم مدیریت نصب کنترل می‌شوند. انتقال مشتریان میرزا در برنامهٔ نسخهٔ بعد است.
